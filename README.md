## 🌐 세계관 & 배경 스토리 (Lore)

> **"신경망에 접속하라, 팬텀. 넥서스는 그림자 속에 도사린 진실을 결코 보지 못할 것이다."**

서기 2088년, 전 세계의 네트워크와 도시를 비밀리에 장악한 초거대 메가코퍼레이션 **넥서스 다이내믹스(Nexus Dynamics)**. 그들은 인류 전체를 영구 감시하고 통제하기 위한 초지능 자율 전투 AI **'오리온(ORION)'**의 가동을 눈앞에 두고 있습니다.

전설적인 고스트 에이전트 **팬텀(Phantom)**이 되어, 지하 2층 물류 주차장부터 옥상 헬리패드에 이르는 넥서스 본사 타워의 **10개 보안 구역**을 침투하십시오. 경비병의 순찰 루트를 파악하고, CCTV 사각지대를 파고들며, 배전반을 쇼트시켜 암전을 유도하고, 최종 메인프레임의 루트 암호 코어를 탈취하여 무사히 탈출해야 합니다.

## 🕹️ 핵심 게임플레이 시스템 (Core Systems)

### 1. 2D 레이캐스팅 시야각 & 소음 시스템 (Stealth Engine)
* **동적 시야 원추 (Dynamic Vision Cone)**:
  * 적 경비병, 360도 스위핑 CCTV 카메라, 자율 비행 드론이 선분 장애물(벽, 기둥, 잠긴 문)을 가로막는 정밀 레이캐스팅 시야를 투사합니다.
  * **🟢 ALL CLEAR (녹색)**: 정상 순찰 상태.
  * **🟡 SUSPICIOUS (황색)**: 소음 감지 또는 의심 물체 목격. 발원지로 이동하여 주변을 두리번거리며 수색.
  * **🔴 RED ALERT (적색)**: 침투 요원 시각적 포착! 전 시설 비상 사이렌 가동 및 **전투 대응 드론 긴급 출격**.
* **음향 전파 메커니즘 (Acoustic Wave Physics)**:
  * **걷기 (`[WASD]`)**: 100% 무소음 이동.
  * **달리기 (`[SHIFT] + [WASD]`)**: 원형 소음 파동 링(Sound Ring)이 사방으로 팽창하여 주변 경비병을 자극.
* **코너 엄폐 & 벽 기대기 (`[SPACE]`)**:
  * 벽에 밀착하여 신체 노출을 최소화하고 시야를 코너 너머로 엿보며 기습 타이밍을 포착합니다.
* **환풍구 통로 (Vents) & 암영 은신처 (Shadow Spots)**:
  * 플레이어 전용 환풍로를 통해 삼엄한 방어선을 우회하고, 어두운 그림자 속에 숨어 적의 유효 감지 거리를 70% 감소시킵니다.

### 2. 비살상 제압 & 시체 은닉 (Takedown & Body Carrying)
* **초크홀드 테이크다운 (`[E]`)**: 경비병의 배후(후방 시야 사각지대)로 은밀히 접근하여 소리 없이 기절시킵니다.
* **시체 운반 (`[G]`)**: 바닥에 쓰러진 경비병을 끌고 이동하여 그림자나 구석진 방, 환풍구 주변으로 은닉할 수 있습니다.
* **동료 발견 시 즉시 경보**: 순찰 중 쓰러진 동료를 발견한 경비병은 즉각 전 시설에 레드 알럿을 발령합니다.

### 3. 환경 인터랙션 & 사이버 해킹 (Gadgets & Hacking)
* **배전반 과부하 (`[H]`)**:
  * 구역 전력망을 쇼트시켜 **25초간 전 구역 암전(Blackout)**을 유발합니다.
  * 암전 중에는 적의 시야 거리가 절반 이하로 줄어들며 모든 CCTV 카메라가 무력화됩니다.
* **보안 단말기 방화벽 침투 (`[H]`)**:
  * 18초간 감시 카메라 화면을 루프(정지)시키고, 맵 상의 잠긴 전자 도어를 일괄 해제합니다.
* **4종 특수 전술 가젯**:
  1. **[1] 무소음 마취총 (Tranq Dart Gun)**: 원거리에서 소음 없이 적을 즉시 기절시키는 다트 발사 (레이저 조준선 지원).
  2. **[2] 소음 유인 폭음탄 (Noisemaker Decoy)**: 마우스 커서 위치로 투척하여 강력한 음파 파동으로 적의 시선을 다른 곳으로 유도.
  3. **[3] 스모크 그레네이드 (Smoke Bomb)**: 10초간 시야를 완벽 차단하는 짙은 연막 구름 생성 (적과 카메라 시야 완전 무효화).
  4. **[4] 광학 위장 클로킹 (Optical Camo)**: 나노 카모플라주를 발동하여 일정 시간 동안 적과 센서의 시선으로부터 완전 투명화.

### 4. 10개 층 침투 캠페인 (10-Sector Campaign)
* **Floor 01 // B2 Subterranean Parking**: 침투 튜토리얼 및 기본 2인 경비
* **Floor 02 // B1 Logistics & Ventilation**: 환풍구 네트워크 및 첫 CCTV 회피
* **Floor 03 // 01F Security Screening Desk**: 보안 검색대 및 잠긴 전자 도어 돌파
* **Floor 04 // 03F Corporate Cubicles**: 오피스 미로와 소음 유인 전술
* **Floor 05 // 05F Bio-Robotics Lab**: 자율 순찰 드론 최초 등장
* **Floor 06 // 07F Data Vault Archive**: 3중 교차 카메라망과 배전반 암전 잠입
* **Floor 07 // 09F VIP Executive Suites**: 광각 시야와 빠른 반응속도를 지닌 엘리트 인포서
* **Floor 08 // 12F Cyber Defense Matrix**: 복합 단말기 연동 및 드론 순찰망
* **Floor 09 // 15F Orion AI Core Sanctum**: 오리온 중앙 서버 5초 다운로드 수성전
* **Floor 10 // Rooftop Sky-Pad Apex**: 옥상 헬리패드 최종 탈출 및 건쉽 랑데부

### 5. 요원 사이버웨어 업그레이드 클리닉 (Agent Progression)
미션 클리어 점수와 스텔스 성과 보너스로 요원의 신체 임플란트를 업그레이드합니다.
* **Cyber-Sprint Legs** (800 CR): 걷기 및 달리기 속도 +25%
* **Silent Padded Soles** (1000 CR): 달리기 시 발생하는 소음 파동 반경 55% 축소
* **Thermal Ocular Implant** (1200 CR): 벽 너머 적의 위치 및 시야각을 미니맵에 투시 (Wallhack)
* **Neural Overclock** (1100 CR): 메인프레임 및 단말기 해킹 시간 40% 단축 (5초 -> 3초)
* **Nano Cloak Capacitor** (1400 CR): 광학 위장 지속 시간을 5초에서 9초로 확장
* **Expanded Dart Holster** (900 CR): 매 미션 시작 시 기본 마취 다트 보유량 +2발 추가

## ⌨️ 조작법 가이드 (Controls)

| 키 / 조작 | 기능 설명 |
|:---|:---|
| **W, A, S, D / 방향키** | 요원 이동 (기본: 완벽 무소음 잠행) |
| **Shift + 이동** | 전력 질주 (이동 속도 증가, **소음 파동 발생**) |
| **마우스 이동** | 조준 방향 및 시선 회전 |
| **Space (길게 누르기)** | 벽 기대기 은신 (피격/감지 면적 감소 & 엿보기) |
| **E** | 적 배후에서 비살상 초크홀드 제압 / 문 개폐 |
| **G** | 쓰러진 시체 끌기 / 내려놓기 토글 |
| **H** | 단말기 해킹 / 배전반 과부하 / 메인프레임 데이터 다운로드 |
| **1 / 2 / 3 / 4** | 가젯 슬롯 선택 (마취총, 폭음탄, 연막탄, 클로킹) |
| **Q / 마우스 우클릭** | 선택된 가젯 발동 |
| **ESC** | 작전 일시정지 (PAUSE) / 재개 |
| **Enter** | 타이틀 시작 / 다음 층 진입 / 결과 확인 |

## 🛠️ 기술적 특징 (Technical Highlights)

* **Zero External Dependencies**: 일체의 외부 CDN, JS 프레임워크, CSS 프레임워크, 외부 폰트 없이 오직 표준 HTML5/CSS3/JavaScript만으로 구현.
* **100% Procedural Web Audio API**: 외부 오디오 파일(.mp3, .wav) 없이 브라우저 오실레이터, 화이트 노이즈 버퍼, LFO 모듈레이션을 통해 심장 박동음, 사이렌, 소음기 발사음, 전기 스파크음 등을 실시간 합성.
* **Deterministic Raycasting**: 2D 가시성 다각형 알고리즘을 통한 부드러운 시야 차폐 및 그림자 렌더링.
* **Real-time LocalStorage Persistence**: 해금된 층수, 보유 크레딧, 사이버웨어 장착 현황, 층별 최고 랭크를 실시간으로 저장 및 복원.
